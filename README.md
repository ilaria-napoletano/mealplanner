# Menu Fuori Sede - HTML Project Viewer

Applicazione web e raccolta schermate UI per il meal planner "Menu Fuori Sede", generato con Google Stitch.

## Contenuto
- `index.html`: Web application completa con pianificatore pasti settimanale, ricette e lista della spesa interattiva.
- `menu_settimanale_1/`: Schermata Menu Settimanale (HTML + Tailwind e screenshot)
- `lista_della_spesa_1/` & `lista_della_spesa_2/`: Schermate lista della spesa
- `ricette_fuori_sede/` & `ricette_dolci_fuori_sede/`: Ricette e preparazioni
- `spesa_conti_coinquilini/`: Gestione spese e divisione conti coinquilini
- `tavola_editoriale/`: Design System e linee guida (`DESIGN.md`)

## Deploy su Render (Static Site)
1. Crea un nuovo repository su GitHub e carica questo progetto.
2. Su [Render](https://dashboard.render.com/):
   - Clicca su **New +** -> **Static Site**.
   - Connetti questo repository GitHub.
   - Lascia il **Build Command** vuoto (o `-`).
   - Imposta **Publish Directory** su `.` (root).
   - Clicca su **Create Static Site**.
